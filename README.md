# HookAll 互联网开发文档

## 概述

HookAll 互联网开发文档是一个**丰富、高质量、开源**的 Web 开发文档库，致力于为开发者提供全面的学习资源。

## ✨ 核心特点

### 丰富

- **基础技术**：JavaScript、HTML、CSS、node、git
- **应用技术**：框架、构建工具、工程化
- **扩展技术**：3D、后端、运维、测试、移动端、命令行、Electron、Web安全
- **前沿探索**：WebAssembly、AI、Web3

### 高质量

- **内容精炼**：聚焦技术核心概念
- **易于理解**：追求通俗易懂的表达方式
- **深度延伸**：通过外链提供技术细节的深入解析

### 开源

- **开放共享**：所有内容采用知识共享 4.0 许可证（与维基百科相同）
- **社区驱动**：网站源于开源项目，持续接受社区贡献
- **代码透明**：网站源代码托管于 GitHub，完全公开可访问

## 📚 文档结构

文档按照技术类别和难度层级组织，帮助开发者从基础到进阶系统学习。
